Music

The original Doom 64 music is in a MIDI format but uses a custom soundset. The link below lists the original tracks and how they are referenced in most engines.

  • Original Music List

On PC ports of Doom 64, specific tracks can be assigned to levels with the MAPINFO text lump. On console ports, the track assignments are hard coded into the engine code. It is possible to compose custom music for Doom 64 where a Doom 64 MIDI Archive exists. The page below describes how to compose music for Doom 64 and lists useful software.

  • Music Composition

The various Doom 64 engines have different music format requirements as described in the following sections.

Doom 64 Remaster and EX+

The official Doom 64 Remaster and EX+ are based on the FMOD sound effects engine. This allows these engines to load other music formats such as MP3, OGG, Impulse Tracker and others. The caveat is the MIDI music is based around the DLS format which has lost the stereo panning of the original Doom 64 Soundset. This can be remedied by adding the stereo information to the MIDI files themselves. When replacing music on the Doom 64 Remaster, replacing single tracks (such as MUSDONE) can cause a bug where music gets played out of order or simple is not replaced. However, replacing the entire soundtrack seems to remedy this bug. And adding new music to custom WAD does not seem to cause this bug. Custom music can be placed between "DM_START" and "DM_END" markers in both of these engines.

If you wish to use MIDI style music with custom sounds, it is recommended that you use tracker formats. Open MPT is software in which you can compose tracker music, but perhaps more importantly, you can convert MIDIs into tracker music with custom soundfonts. In particular, these engines support the impulse tracker (IT) format.

It is possible to edit the "DOOMSND.DLS" sound bank file for custom music. This is in the somewhat obscure DLS (downloadable sound) format, however, it is the only soundfont that the FMOD sound effects engine currently supports. Aging and expensive software such as Awave Studio can edit this file.

Doom 64 EX Engines

The sound system for Doom 64 EX based engines utilize the FluidSynth sound system. Fundamentally this system is based upon MIDI architecture and all of its music and in-game sounds are in a soundfont. This engine only supports MIDI music. Here music is placed between the "DS_START" and "DS_END" markers of a custom WAD.

The original Doom 64 EX requires additional formatting which can be done with the MIDI 64nicator. This is due to many MIDI events causing the engine to crash and must be cleaned from the files. This engine also suffers from tracks going out of sync when a high density of midi events occur, however this is not noticeable with low-density ambient tracks.

FluidSynth supports chorus and reverb effects, thus Doom 64 EX based engines do as well. These are controlled by specific MIDI events in the music files and can give the music more depth. If you decide to use these effects, it is recommended you set the amplitude of these effects to zero in MIDI channels that do not use them. Otherwise the reverb and chorus settings from a previous music track can bleed over.

If you would like to change the sounds used in the music in these engines, you will need to edit the soundfound, DOOMSND.SF2. This soundfont is based on the common SF2 format. Soundfont editing can be done with the Polyphone Soundfont Editor software and many other modern applications.

Nintendo 64

For the Nintendo 64 engines, none of the sound and music assets are stored in the WAD, rather they are stored in three files for the WESS/NESS sound system.

  • WDD - WESS Data Directory - Raw audio files
  • WMD - WESS Module Directory - Sound playback properties
  • WSD - WESS Sequence Directory - Sound sequences

These are formats originating from Williams Entertainment where wadutil64 can convert MIDIs and soundfonts to these files. The WSD file contains the sound sequences which includes music but also intitiates gameplay sounds. On the Nintendo 64, these are entirely loaded in the system RAM where any changes to WSD also requires changes to the audio heap size.

The original Doom 64 sounds are 11.025 kHz, 16 bit, but are nearest-neighbor (square) interpolated to 22.05 kHz, 16 bit during playback.
